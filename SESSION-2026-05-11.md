### Image generation
- **`scripts/generate-service-images.ts`** — calls OpenRouter `/chat/completions` with `modalities: ['image', 'text']`
- Default model: `openai/gpt-5.4-image-2`
- Style: dark isometric low-poly, monochrome + green accent, crosshair markers — matches site brand
- Saves to `/public/services/<slug>-<n>.png`
- Service page auto-detects via filesystem check, falls back to `/img1.webp` etc.
- **Cost**: ~$0.05–0.07 per image, ~$2.50 for all 45
- Run: `npm run gen:images` (optional `--service=<slug>`, `--block=<n>`, `--dry-run`, `--force`)
